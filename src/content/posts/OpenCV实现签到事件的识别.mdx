## 0x02 取会议窗口图片

首先当然可以直接截整个窗口的图，但是分析起来时间较长，比较占用资源，遂用FindWindow方法取腾讯会议的Hwnd，然后调用Pillow的GrabImage方法就行，于是第一版代码如下

``` python
hwnd = win32gui.FindWindow(None,'腾讯会议')
rect = win32gui.GetWindowRect(hwnd)
img = ImageGrab.grab(bbox=rect)
```

然而问题被发现了，截图的区域始终异常，于是打开Spy++查看取的句柄是否正确。

在通过Spy++查看后，发现了三个同名且同类名的窗口，且不属于父子关系，于是不能直接使用FindWindow方法来取窗口的hwnd。

通过Spy++可以看见，因为他们的窗口差异只有Client Rect和Rectangle。观察可知，要找的主窗口的窗口尺寸最大。所以可以通过EnumWindows方法枚举所有的窗口句柄，然后在通过Callback回调函数将符合条件的句柄加入list中在进行筛查和处理

``` python
def callback(hwnd, rects):
    rect = win32gui.GetWindowRect(hwnd)
    if win32gui.GetWindowText(hwnd)=='腾讯会议':
        rects.append(rect)        
    return

def getWindowPos():
    rects = []
    win32gui.EnumWindows(callback,rects)

    rectSize = -1
    mainRect = None

    for rect in rects:
        currSize = (rect[2]-rect[0])*(rect[3]-rect[1])
        if int(rectSize) < int(currSize):
            mainRect = rect
            rectSize = currSize

    return mainRect

def getScreenImage(windowRect):
    img = ImageGrab.grab(bbox=windowRect)

    return img
```

## 0x02 寻找目标

拿到窗口图片以后要做的就是定位目标，想到的方案有两种，1是OCR定位文本，2是模板匹配。

``` python
def findButtonOCR(img,text):
    result = pytesseract.image_to_data(img,output_type=Output.DICT,lang='chi_sim')

    for i in range(len(result['text'])):
        if result['text'][i] == text:
            (x,y,w,h) = (result['left'][i],result['right'][i],result['width'][i],result['height'][i])
            return [int(x+w/2),int(y+h/2)]
        
    return None

def findButtonCV(pilImg,pattern,rect):
    confidence = 0.95
    cv2Img = cv2.cvtColor(numpy.asarray(pilImg),cv2.COLOR_RGB2BGR)
    pattern_img = cv2.imread(pattern)

    result = cv2.matchTemplate(cv2Img,pattern_img,cv2.TM_CCORR_NORMED)
    w,h = pattern_img.shape[::2]
    min_val,max_val,min_loc,max_loc = cv2.minMaxLoc(result)

    if max_val > confidence:
        x = int(max_loc[0]+w)
        y = int(max_loc[1]+h)
        return x+rect[0],y+rect[1]
    
    return None

```

很快啊，两个代码就敲出来了，由于pytesseract中文的OCR识别效果太差，就没有采用了，实战采用的是opencv-python来做模板匹配，这里用的confidence是0.95，足以稳定应付固定模板了

## 0x03 后续细节

拿到坐标以后的后续操作就比较简单了，移动只需要调用SetCursorPos，点击调用mouse_event，定时入会操作其实在高版本的腾讯会议中有小trick

``` sh
start wemeet://page/inmeeting?meeting_code={MeetingId} 
```

通过这个链接即可直接调用腾讯会议，所以实现起来并无难度
